# notes-style · 打卡笔记写作规范

## Overview
本技能定义团队打卡笔记的结构与文风。凡涉及"写笔记 / 写心得 / 按规范整理记录"的请求都应遵循本技能。

## Instructions

### 1. 读取完整规范
先用 read_file 读取参考文件 `/skills/notes-style/references/structure.md`，其中定义了笔记的六段式结构。

### 2. 按规范产出
- 严格遵循六段式结构，不遗漏段落
- 「学习心得」必须 ≥50 字、第一人称、包含真实观察
- 引用资料一律放到文末「引用资料来源」段

### 3. 自检
产出后逐段核对结构是否完整，并向用户报告核对结果。
